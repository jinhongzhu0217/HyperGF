# 针对基于分子特征提取的分子代谢稳定性预测任务



# 模型框架
![image](https://github.com/user-attachments/assets/63866add-da93-4db7-aa20-b283b54d7f02)

A部分为多模态编码器，从左到右分别为分子的指纹特征编码器、分子的药效团特征编码器和分子的图结构特征编码器。
B部分为模型的框架，从左到右分别为简单的线性变换层，超图卷积网络和图同构网络。
C部分为特征融合部分，采用了自注意力融合机制。D部分即为损失函数设计的部分和模型分类器输出部分，综合考量了分子图对比学习损失和真实标签与预测标签的损失。
E部分为分子图对比学习的过程，即药效团超图和分子图进行对比学习，生成一个损失值。
